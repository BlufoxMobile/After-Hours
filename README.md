# After-Hours

An arcade survival game set inside an Xfinity store after closing. Play as the Blufox.

Play it: https://blufoxmobile.github.io/After-Hours/

## The run

120 seconds. Your fox auto-fires at the nearest target, so movement is the whole game.

**Move** — left stick, or WASD / arrow keys

**Dash** — Space. Invincible for the burst, and it shreds anything you pass through.

**Pulse** — E. Damages everything nearby and wipes incoming shots.

**Chain kills** to raise the score multiplier and fill OVERDRIVE.

## What is in the store

Grunts, zig-zag runners, red chargers that wind up and rocket at you, purple spitters that keep their distance, green splitters that break into mites, and gold-ringed elites with extra armor. Ceiling sparks start dropping after 30 seconds. Router Rage shows up at 42s; Cable Chaos arrives at 78s with three phases and an enrage.

## Notes

Single self-contained HTML file with the art embedded — nothing to install. High scores are stored per browser.
